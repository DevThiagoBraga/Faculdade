# 🎓 Projetos da Faculdade – Ciência da Computação

Bem-vindo ao meu repositório de projetos desenvolvidos durante a graduação em **Ciência da Computação**.

Aqui você encontrará atividades, exercícios, trabalhos acadêmicos e projetos práticos realizados ao longo da minha formação. O objetivo deste repositório é documentar minha evolução como desenvolvedor, registrar meu aprendizado e compartilhar soluções para diferentes problemas utilizando diversas tecnologias.

## 📚 Objetivos

* Organizar todos os projetos da graduação em um único local.
* Acompanhar minha evolução técnica ao longo do curso.
* Compartilhar conhecimento e boas práticas de programação.
* Construir um portfólio sólido para oportunidades profissionais.

## 💻 Tecnologias

## 📁 Organização

Cada pasta representa uma disciplina, projeto ou atividade específica, contendo:

* Código-fonte
* Documentação
* Relatórios (quando aplicável)
* Arquivos de apoio

## 🚀 Evolução

Este repositório será atualizado constantemente conforme novas disciplinas forem concluídas e novos projetos forem desenvolvidos.

## 📖 Objetivo Pessoal

Acredito que a melhor forma de aprender programação é praticando. Por isso, utilizo este espaço para registrar minha jornada na Ciência da Computação e desenvolver habilidades que me preparem para os desafios do mercado de tecnologia.

## 🤝 Contribuições

Este repositório possui caráter acadêmico. Sugestões de melhorias, boas práticas e feedbacks são sempre bem-vindos.
